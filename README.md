Entry for the [make.fun bounty "Invent a Word We Need"](https://make.fun/bounty/u-deranalabs-invent-a-word-we-need-17a020e0).

**Entry (86 characters):**

> introblank — forgetting someone's name at the exact moment you start introducing them.

`main.ts` writes this one coined word + one-line definition to `/output/entry.txt`, deterministically, with a built-in gate self-check (1–140 characters).

**Why introblank:** a transparent coinage (intro + blank) for a universal, embarrassing gap — going blank on someone's name at the exact moment you start introducing them. The definition is a single self-contained clause with a specific time twist; the word is sayable, spellable, and memorable. Chosen over 5 other clean candidates (callclash, walksync, fridgehope, goodbyeloop, doorjog) by pairwise comparison against the judge's criteria; 4 more candidates (roomnesia, miswave, pocketpanic, pageloop) were rejected because the words already exist.
